# Spor ve Sağlık Dünyası - BLM2537 Dönem Projesi

Bu proje, Ağ Tabanlı Programlamaya Giriş dersi kapsamında geliştirilen VKİ (Vücut Kitle İndeksi) takip ve sağlık platformudur.

## Kullanılan Teknolojiler
- HTML5 (Semantik etiketler, form ve tablo yapıları)
- CSS (Flexbox, CSS değişkenleri, Medya sorguları ile mobil uyum)
