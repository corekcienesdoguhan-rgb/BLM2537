# Spor ve Sağlık Dünyası - BLM2537 Dönem Projesi

Bu proje, Ağ Tabanlı Programlamaya Giriş dersi kapsamında geliştirilen VKİ (Vücut Kitle İndeksi) takip ve sağlık platformudur.

## Kullanılan Teknolojiler
- HTML5 (Semantik etiketler, form ve tablo yapıları)
- CSS (Flexbox, CSS değişkenleri, Medya sorguları ile mobil uyum)
- JavaScript (İlerleyen haftalarda form işlemleri ve dinamik hesaplama için dahil edilecektir)

## Projeyi Çalıştırma Adımları
1. Bu depoyu bilgisayarınıza klonlayın veya ZIP olarak indirip çıkartın.
2. Proje klasörünü Visual Studio Code ile açın.
3. `site` klasörü altındaki `index.html` veya `dersler.html` dosyasına sağ tıklayın.
4. "Open with Live Server" seçeneğini seçin.
5. Sayfa varsayılan tarayıcınızda açılacaktır.

## Haftalık İlerleme Özeti
- **1. Hafta:** Semantik HTML yapısının kurulması, harici CSS dosyasının bağlanması ve temel sayfa düzeni.
- **2. Hafta:** VKİ formuna cinsiyet radio butonlarının eklenmesi, min/max sınırları ile doğrulama, radio buton genişlik düzeltmesi ve VKİ tablosuna colspan satırının eklenmesi.
- **3. Hafta:** VKİ form elemanlarına ID tanımlamaları, sonuç kutusu (#vki-sonuc) ve JS hazırlık sınıfları (.gizli, .hata), tfoot ile semantik tablo yapısı, overflow-x ile mobil tablo kaydırma ve responsive medya sorgusu iyileştirmeleri.
